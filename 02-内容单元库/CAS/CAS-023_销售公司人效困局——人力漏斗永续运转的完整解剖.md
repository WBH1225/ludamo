## 连麦场景

03年出生，创业三四年，销售公司——一直亏。"两个销售经理，一部能力强，二部能力弱。不知道怎么把员工人效拉上来。销售朝九晚六——同行业都这么招，不这样我扩不到四十人团队。"

## 人力漏斗停了

对方说"人效低"——但人效是结果，不是动作。鲁大魔不进"怎么拉人效"框架——进"你做了什么"框架：

| 应该做的事 | 实际做了什么 |
|-----------|------------|
| 裁掉业绩差的 | 没裁——留着养老 |
| 多招HR筛人 | 只有2个HR |
| 继续筛继续裁 | 没有循环 |
| 前三个月让销售熬 | 朝九晚六——最轻松的电销公司 |

**"裁掉裁掉裁掉，筛人继续招，多招两个hr……把人裁掉让hr继续招继续筛。"**

## 人力漏斗四步运转

```
大量招聘（多招HR→扩候选人池）
    → 工作试用（前三个月熬一熬→真实工作量检验）
    → 结果筛选（销冠vs普通人→数据说了算，不是感觉）
    → 淘汰差的（裁掉→不犹豫→裁完继续招）
    → 循环（漏斗不停）
```

**招10个→试3个月→留2个=正常比例。** 你不裁人=漏斗堵了=差的留在系统里=拉低了整个人效平均值。你不是"不知道怎么拉人效"——你是没做过基本管理动作：裁人、招HR、筛人。

## 朝九晚六=养老模式

销售岗尤其是电销——前三个月最关键。话术需要大量重复练习，销冠是靠电话量堆出来的（他打20个你打10个）。"同行业都这么招"=借口。你不是在管理销售公司——你在开养老院。
