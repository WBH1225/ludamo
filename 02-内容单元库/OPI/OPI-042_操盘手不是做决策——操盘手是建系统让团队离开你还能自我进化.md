## 核心内容

**"真正的操盘手是从把业务从零到一的搭建，把每一个该做的指标，该拓展的渠道，该招募的人力，把公司的工作流程都给他理清楚，并且把人员匹配，能够让整个的团队在离开自己的情况下能够自我进化，自我工作，这才叫真正操盘手。"** ——[[LD-106]]

### 操盘手=七步定义链

```
搭建业务 → 设定指标 → 拓展渠道 → 招募人力 → 理清流程 → 匹配人员 → 团队自我进化
```

七个动词——没有一个跟"做决策"有关。

### 两种定义的对比

| 流行理解 | 正确理解 |
|----------|---------|
| 做决策 | 建系统 |
| 发号施令 | 设定指标 |
| 不用自己干 | 让别人能干 |
| 解脱 | 更高强度的创建 |
| 头衔 | 结构完成后的自然身份 |

### "操盘手"概念消毒

他说"我想当操盘手"=他在用高级职业标签包装"我不想被绑在小县城"。鲁大魔拆穿：你不是想当操盘手——你是想逃离。逃离没有错——但你用了一个你不认识的概念来包装逃离——概念=欲望的化妆品。

**"痴心妄想症，大概率是一个傻逼"**=概念暴力——如果你连定义都不对，你连问"怎么成为"的资格都没有。先知道什么是操盘手——然后你就不想当了——然后你才开始真正建系统——然后你才是。
