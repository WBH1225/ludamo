## 核心内容

**"都别做。大钱都是有积累的。餐饮短周期不长久。你卖肉反而是长周期。你有想法先观察一年——存量市场什么时候做都不晚。"** ——[[LD-413]]

### 可控→不可控=倒退

| 维度 | 生鲜肉 | 餐饮 |
|------|--------|------|
| 核心要素 | 肉（可控） | 厨师（不可控） |
| 积累 | 两年渠道+客源 | 从零 |
| 周期 | 长（稳定复利） | 短（高淘汰） |
| 累的性质 | 熟悉的累（有利润扛） | 新的累（没利润扛） |

### "因累而逃" vs "因机会而进"

```
因累而逃 = 大概率逃进新坑 → 亏存款+丢老客 → 又回来卖肉 = 白亏
因机会而进 = 观察一年 → 要么省了亏一笔 → 要么准备好了 = 成功率高
```

**关键区分：先观察一年。** 一年后累过去了=你可能发现卖肉没那么糟。一年后机会确认了=你跳得比谁都稳。
