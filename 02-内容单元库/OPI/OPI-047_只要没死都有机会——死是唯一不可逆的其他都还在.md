## 核心内容

**"只要没死人都有机会。不要把这个大龄成为自己压力。有粉丝四十岁四十五五十岁来问我还能不能开始。"** ——[[LD-379]]

### 死=唯一不可逆

```
没结婚 = 还在 → 可以结
没工作 = 还在 → 可以找
亏了钱 = 还在 → 可以再赚
死了 = 不可逆 → 机会归零
```

手还有温度=机会还在。手没了=没机会。你想要机会=就握住——而不是问"我年纪是不是大了"。

### "被歧视"的语法检查

"被歧视"=被动语态。被动=你在承受。承受=你给了外界判你的权利。你不签字=判决无效。换法庭→去"有能力的人都在哪里"法庭→没人问年龄→只问你能做什么。
