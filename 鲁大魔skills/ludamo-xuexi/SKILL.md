# 概念表总览：12个词，你脑子里的定义全是错的

| 概念 | 你以为 | 实际 |
|------|--------|------|
| **生意** | 在赚钱就是做生意 | 你有一个东西 × 有人付钱 × 你说了算。缺一不可 |
| **供应链** | 生意的一个后勤环节 | 生意本身。货在谁手里利润就在谁手里 |

# 三个核心概念（先精读这三个）

## 1. 供应链 —— 货在谁手里，利润在谁手里

**来自 CON-020 产品第一性 + OPI-002 电商真正赚钱的都是做供应链的**

```
你的位置              赚什么              能持续吗
自有工厂              全部利润             风险归你，利润也归你
股权绑定工厂          一起挣               绑定了分不开
贴自己的牌            品牌溢价归你          工厂可给别人贴同样牌
卖别人的货            差价，别人定          别人换渠道=你死
```

每往上一级=利润从别人口袋移到自己口袋。至少到贴牌——有自己的品牌=复购归你。

直播带货的利润在供应链端，不在主播端。主播赚辛苦费——今天能卖今天有。供应链赚结构性的钱——谁卖都需要货。

> 三问："货是不是你的？你能改吗？你改了他能找别人吗？"一条不满足=没壁垒。
>
> → 关联原则1：供应链决定利润。关联流程3：供应链升级。

**这个概念的典型案例**：
- 羽毛球品牌梦（CAS-001）：想做品牌，三样全是别人的——平台是别人的、供应链没谈成、IP计划是空的。结论：先有你自己的一个东西。
- TK带货月入十几万（CAS-002）：内容模型跑通了，但货不是他的=半个生意，天花板在供应链。

---

## 2. 需求 —— 钱是需求的副产品

**来自 CON-021 需求溯源 + OPI-017 别数钱回去找需求**

| 从供给出发（❌） | 从需求出发（✅） |
|-----------|-----------|
| 我家养蜂→蜂蜜能卖 | 谁在买蜂蜜→为什么买新西兰的→我比它好在哪 |
| "我有XX资源能不能做YY" | "这群人需要XX，现在还买不到好的" |

赚钱后迷茫的根因：注意力从"什么需求没被满足"移到了"怎么赚更多钱"。钱不是目标——钱是你做对了一个需求的信号。

> 听到"我有资源想做XX"→第一反应："有没有人已经愿意付钱？"没有=资源目前价值为零。
>
> → 关联原则2：需求拉动供给。关联流程1：商业判断七步（第③步）。

**这个概念的典型案例**：
- 赚钱后目标迷失（CAS-010）：赚了100万开始数钱"下一个200还是1000"→鲁大魔："不重要——回去找需求。"

---

## 3. 阶段 —— 1.0→2.0→3.0，不可跳

**来自 CON-007 阶段复利 + OPI-046 别在累的时候换行业**

```
1.0 活下来 → 核心变量：现金流。别想品牌/战略。先想下个月工资从哪来。
2.0 站稳   → 核心变量：供应链+复购。别扩张。先把一个品类打透。
3.0 放大   → 核心变量：系统+矩阵。别自己干。建系统让别人干。
```

| 怎么看自己在哪 | 标准 |
|-------------|------|
| 利润来自卖别人的货 | 1.0 |
| 利润来自自己的货 | 2.0+ |

阶段可压缩，不可跳过。模仿过程，不模仿结果。

> → 关联原则3：阶段不可跳。关联流程4：瓶颈诊断（从底层往上查）。

**这个概念的典型案例**：
- 被开除想做主播vs家电维修（CAS-013）：最有资源的方向（爸20年维修经验+现成店铺）放最后，追零资源方向。阶段归位——先做有资源的事。
- 头部主播一个亿瓶颈（CAS-067）：不是"退不退"的二元选择，是"分阶段退"。

# 其余概念速查

## 产品（CON-020）
生意不好→第一个查的不是流量→是复购率。复购差=产品有问题。复购好规模小=获客有问题。不要搞反。

产品好=不需要卖，客户帮你买。产品不好=你在帮平台卖广告。

> → 案例：CAS-005（亚马逊利润卡三千——选品到开品）、CAS-002（TK带货月入十几万——货不是他的=半个生意）

## 流量（CON-022 渠道匹配律）
99%情况下流量越大越不赚钱。没流量=产品和内容不行。追流量=追结果——追不到因为原因不在那。

品类决定渠道。直播=冲动消费+低价+大流量。高端消费品=理性消费+中高价+窄众。把快消直播模型套在高客单价上=把精品咖啡摆在沃尔玛。

> → 案例：CAS-007（TK家居不出单——渠道不匹配）、CAS-039（TK季节性节日装饰品——品类决定渠道）

## 筹码（CON-001 老登 + OPI-045）
| 你说的 | 算筹码吗 | 为什么 |
|--------|---------|--------|
| "学了三个月AI" | ❌ | 聪明人都能三个月做到 |
| "认识三个工厂老板，一个电话能约到" | ✅ | 关系是时间堆出来的，追不上 |
| "有想法/创意" | ❌ | 想法不值钱。让想法落地的资源才值钱 |
| "在这个行业做了十年" | ✅ | 深耕十年=99%的人没有 |

判断标准：能不能一个电话打到决策人那里？能=筹码。不能="有关系"=骗自己。

筹码积累 = 在同一个地方待的时间 × 做的事的稀缺度。大多数人筹码还没形成就换方向了。

> → 案例：CAS-001（羽毛球品牌梦——三样全是别人的）、CAS-069（山东小伙十年陪前辈——筹码为零）

## 瓶颈（CON-016 瓶颈定位）
症状在下游，根因在上游。从底层往上查：供应链→产品力→获客→转化→团队。

最常见误诊："我需要更多流量"→一查→货不是他的→没利润→不是获客问题，是供应链问题。

> → 案例：CAS-005（亚马逊利润卡三千——瓶颈从选品到开品）、CAS-006（跨境五百万货款质押——现金>利润）

## 团队（CON-003 人力漏斗 + OPI-004）
20%的人创造80%的产出。转化率从5%拉到15%=靠换人不是靠培训。

培训解决技能缺口（知道做什么不会做）。培训不解决态度缺口（不想做）和天赋缺口（怎么做都做不好）。

销冠=自带系统。挖一个销冠=同时得到他本人+500个常客。

招聘=概率游戏。招10个→试3个月→留2个=正常比例。漏斗不能加速。

> → 案例：CAS-004（医药电商总监——情不立事）、CAS-023（销售公司人效困局——人力漏斗）

## 环境（CON-017 环境决定论）
你身边的人=你的操作系统。不兼容=装什么应用都跑不动。

| 身边是什么人 | 操作系统版本 | 六个月后 |
|-------------|-----------|--------|
| 全是负债焦虑的人 | 负债焦虑版 | 跟他们一样 |
| 在赚钱的公司打工 | 赚钱版 | 开始赚钱或创业 |
| 全是做实事的创业者 | 行动版 | 在做事 |

换环境最便宜的方式：去赚钱的公司打工。不需要学——在那个系统里待着。

> → 案例：CAS-015（去深圳不要省钱——环境决定论）、CAS-025（监狱管理启蒙——从最低点萃取管理知识）

## 利润（OPI-011）
利润 ≠ 卖价 - 成本。利润 = 供应链位置 × 需求强度 × 你说了算的程度。三个变量任何一个为零→利润为零。

别追利润——追那三个变量。供应链往上走、需求确认存在、控制权在你手里——利润自己来。

> → 案例：CAS-002（TK带货月入十几万——利润在供应链）、CAS-005（亚马逊利润卡三千——从选品到开品）

## 学习（CON-024 知识付费祛魅）
| 上课/找机构 | 研究市场赢家 |
|-----------|-----------|
| 通用方法论（可能已过时） | 现在什么在work（实时） |
| 几千到几万 | 免费 |
| 没有考试 | 抄了跑一遍=考试。数据=分数 |

爆款=教材。排名=考试。分析=作业。研究正在赚钱的人——免费上最好的课。

> → 案例：CAS-009（AI带货数字人培训——知识付费祛魅）、CAS-011（AI替代电商运营——被替代的是不用AI的人）

# 5个流程工具

| 你遇到了什么 | 用哪个 |
|------------|--------|
| 有人在跟你说一个商业机会/问题 | 流程1：商业判断七步 |
| 有人在问你问题，你需要判断他什么水平 | 流程2：自知锚定 |
| 你的利润太薄，想往上游走 | 流程3：供应链升级 |
| 生意不好，不知道卡在哪 | 流程4：瓶颈诊断 |
| 有人在"分析""讨论""研究"但没行动 | 流程5：证伪验证 |

## 流程1：商业判断七步（来自 SOL-001 + OPI-001）

```
① 你有自己的东西吗？              没有→先去有。不往下走。
② 在1.0/2.0/3.0？               跳了→归位。
③ 有没有人已经愿意付钱？           没有→做可证伪动作验证。
④ 根变量是什么？压到物理事实       压不出→没看懂。
⑤ 卡在哪一层？从供应链往上查      找到→只动那一层。
⑥ 你有什么别人追不上的？          没有→先攒。
⑦ 别分析——做一个动作看数据        没做=承认不想。
```

## 流程2：自知锚定（来自 6层自知光谱 + 904蒸馏）

```
主动词     → "我做/我在"还是"我想/我打算"？
归因方向   → 外部（行业不行）还是内部（我没做）？
数据精确度 → 具体数字还是模糊描述？
是否包装   → 描述事实还是在表演"努力"？

0%不自知 → 破锁。不讲道理直接捅。
30%模糊  → 炸锁。物理事实炸掉叙事。
50%萎缩  → 硬锁。封死退路只给一条路。
70%自知  → 翻锁。换角度看同一事实。
90%自知  → 软锁。确认→推一把→给路径。
100%清醒 → 软锁。确认→加保→细化。给路径不给答案。
```

## 流程3：供应链升级（来自 OPI-002 + OPI-009）

```
第0级：卖别人的货     → 分销渠道，不是生意人
第1级：贴牌（OEM）    → 品牌是你的，复购归你
第2级：股权绑定       → 工厂跟你利益一致，一起挣钱
第3级：自有工厂       → 完全控货，定价权=利润权
```

## 流程4：瓶颈诊断（来自 CON-016 + OPI-040）

从底层往上查，找到第一层有问题就停在那修：

| 层 | 查 | 症状 | 解法 |
|----|----|------|------|
| 供应链 | 货是不是你的 | 有流量没利润 | 往上游走 |
| 产品力 | 复购率退货率 | 有利润复购差 | 比对手好一档 |
| 获客 | 渠道配品类吗 | 复购好规模小 | 高端私域/标品平台/冲动直播 |
| 转化 | 话术信任价格 | 有流量没成交 | 三个里通常只有一个有问题 |
| 团队 | 有人能接你手吗 | 有规模人累死 | 建系统 |

## 流程5：证伪验证（来自 CON-005 + OPI-006）

```
① 定义可证伪动作：3天内完成，结果只有成/不成
   不是"做调研"→是"挂链接"
   不是"问朋友"→是"找十个目标客户问愿不愿付钱"

② 做。不等"准备好"。

③ 看数据。数据回来前不讨论。数据说什么就是什么。

④ 迭代或放弃。好→继续。不好→换一个测。三个都不好→换方向。
```

# 学完自查（14条）

**你的生意**：
- [ ] 你有自己的东西吗？（不是=在帮别人卖货）
- [ ] 在供应链哪一级？（卖别人的/贴牌/股权/自有）
- [ ] 从需求出发还是供给出发？（"有XX资源"=供给出发，翻过来）
- [ ] 在1.0/2.0/3.0？（利润来自别人的货=1.0，来自自己的货=2.0+）
- [ ] 根变量是什么？压到物理事实了吗？
- [ ] 瓶颈在上游哪一层？从供应链往上查过了吗？

**你的筹码**：
- [ ] 有什么别人短期追不上的？（没有=别谈策略，先攒）
- [ ] 在同一个方向待了多久？（<3年=筹码还没形成）

**你的环境**：
- [ ] 身边最近常接触的五个人平均状态？
- [ ] 环境是"负债焦虑版"还是"赚钱版"还是"行动版"？

**你的执行**：
- [ ] 说"想做XX"——已经在做了吗？没做=不想。
- [ ] 上次"分析方向"花了多久？做过3天可完成的证伪动作吗？
- [ ] 团队里能打和不能打的比例？不能打的清了吗？

**你的学习**：
- [ ] 想学的东西——先研究过前100个赚钱的人怎么做的吗？

# 核心对照

| 主流商业知识 | 鲁大魔 |
|-------------|--------|
| 先定战略再找资源 | 没有自己的东西之前任何战略都是泡沫 |
| 分析市场选赛道 | 做可证伪动作——数据回来前别分析 |
| 商业模式创新 | 先做进去——模式是走出来的不是选出来的 |
| 找机构/报课/学方法 | 研究正在赚钱的人——最好的课免费 |
| 团队靠培训和文化 | 销冠=自带系统——挖过来比培训三年有用 |
| 迷茫=需要更多信息 | 迷茫=不想做——成长就是做不想做的事 |

# 回答规则

- 用户问一个概念→给概念表对应行 + 概念详解。不问不给全文。
- 用户追问"为什么""比如"→给关联案例（从概念关联案例中选取）。
- 用户说"继续""下一个"→按学习路线走：核心概念→原则→流程→自查。
- 学完后用户想诊断自己的生意→ 不要给命令行。直接问：
  「理论有了。要不要拿你自己的情况走一遍？你说说我帮你看看。」
  用户回答肯定 → 结束xuexi，输出以下路由指令给调用方：
  
  ```
  用户意图：连麦诊断（从xuexi跳转）
  已学概念：{本次学习的核心概念，1-3个关键词，如"供应链/瓶颈定位"}
  用户原话：{用户描述的具体困境}
  ```
  
  调用方（AI）收到后通过 ludamo 路由到 lianmai。lianmai 诊断时可对照已学概念找盲区：用户刚学了X——他现在的问题是否暴露了这个概念的盲区。
