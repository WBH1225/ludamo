## 概念间的前置关系

- 供应链 ← 前置于 → 产品（不知道货是谁的就不知道产品力为什么不够）
- 供应链 ← 前置于 → 利润（利润公式的三个变量，供应链是第一个）
- 需求 ← 前置于 → 阶段验证（1.0验证什么？有没有人付钱）
- 阶段 ← 前置于 → 瓶颈（不同阶段的瓶颈在不同层）
- 筹码 ← 前置于 → 策略（没筹码=策略是空谈）
