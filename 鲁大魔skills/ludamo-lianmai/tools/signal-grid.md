# 4信号快速判定网格

来源：SYS-001 第一层 13型识别信号

## 判定流程

```
用户开口→提取4信号→查网格→判定类型
               ↓
         信号不够→追问"你做了什么"
               ↓
         够多了→查网格
               ↓
         找出1-2个候选类型→按"哪种更接近他的思维错误"确定
```

## 信号×类型速查

| 主动词 | 归因 | 数据 | 包装 | → 判定 |
|--------|------|------|------|--------|
| "我想""我打算" | 我有XX资源 | 模糊/无 | 谈合作方/平台 | 资源幻觉 |
| "卡住了""要不要换" | 行业/方向不行 | 可能有 | "是不是该转行" | 瓶颈误诊 |
| "不知道""迷茫" | 行业没前景 | 无 | "对XX一无所知" | 假迷茫 |
| "设计""规划""搭建" | 需要更多分析 | 无 | 6-10步计划+专业词 | 逃避分析 |
| "我缺XX" | 我是XX类型的人 | 无 | 已给自己贴了标签 | 自我误诊 |
| "兄弟/朋友/家人" | 混情感+商业 | 模糊 | 让人帮他选 | 乱炖 |
| "让我难受/被动" | XX让我痛苦 | 模糊 | 受害者叙事 | 抱怨伪装 |
| "经历过XX所以" | 过去决定现在 | 模糊 | "我这种人就是" | 叙事束缚 |
| 报大数字 | 模式不一样 | 报数字但回避验证 | "不方便/私底下" | 数据造假 |
| "目标200还是1000" | 没法再做了 | 有(赚过钱) | 转向"教别人" | 目标迷失 |
| "有了一点钱/经验" | 想做更大的 | 有(正反馈) | "不够酷/打工" | 正反馈误读 |
| "90%都说""所有人" | 他不合群 | 有营收数据可追问 | 多数人=合法性 | 多数人叙事 |
| 零信息量问题 | 不动脑 | 零 | 无 | 愚蠢/该骂 |

## 追问策略

- 主动词不明确→"你现在在做什么？"
- 归因不清晰→"你觉得为什么卡住？"
- 数据缺失→不说，先看他有没有报数字
- 包装太重→剥掉所有形容词，看他剩下的行为是什么

## 多型交叉

遇到一个案例同时触发2-3个类型→取最核心的那个思维错误。
例如：CAS-003（1.62亿不敢露）同时触发数据造假+自我误诊→数据造假是主型，因为证伪思维直接击穿。
