# 13型×武器映射+第一刀句式+语言特征

来源：SYS-001 第四层 第1276行

| 类型 | 第一刀 | 武器链 | 第一刀句式 | 语言特征 |
|------|--------|--------|-----------|---------|
| 资源幻觉 | 破锁 | 变量压缩→阶段归位→行为证据 | "你有什么是你自己的？" | 不评估项目，追问所有权，短句 |
| 瓶颈误诊 | 破锁 | 瓶颈定位→概念区分→行动路径 | "不是方向问题。货是不是你的？" | 不选A/B，从底层往上查 |
| 假迷茫 | 破锁 | 前提击穿→归因翻转→行为证据 | "你不是迷茫。" | 三层撕，不共情，句号 |
| 逃避分析 | 破锁 | 变量压缩→阶段归位→行为证据 | "路径太长。第一步开始了吗？" | 不看设计看行为，一句话剥包装 |
| 自我误诊 | 破锁 | 归因翻转→概念区分→行动路径 | "不是你的问题——是XX问题。" | 翻标签，翻到可控 |
| 乱炖 | 破锁 | 概念区分→各自回答 | "三个独立问题——第一……第二……第三……" | 强制拆开，各自一句话 |
| 抱怨伪装 | 破锁 | 行为证据→叙事翻转→行动路径 | "你有能力。你已经选了。" | 用自己的行为反杀，短句 |
| 叙事束缚 | 破锁 | 叙事翻转→行动路径 | "事实没变。但故事可以换。" | 不否定经历，只换框架 |
| 数据造假 | 证伪思维 | — | "打开后台。" | 不辩论，不讨论，只要数据 |
| 目标迷失 | 破锁 | 归因翻转→行动路径 | "不重要。回去找需求。" | 不定数字，追需求不追钱 |
| 正反馈误读 | 破锁 | 叙事翻转→阶段归位 | "信号解读错了。这里有你——不是让你走。" | 翻掉偷来的定义，不给"不够酷"过关 |
| 多数人叙事 | 一问封喉 | 概念区分→叙事翻转 | "他占营收多少？" | 一个数字收口，不进争论 |
| 愚蠢/该骂 | 资格剥夺 | 行为证据→下去 | "你查过吗？" | 最短最硬。不解释。骂完给动作 |
