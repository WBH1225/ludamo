## 一、SYS-002 10案例判定验证

### 验证方法

每个案例执行：4信号提取 → 类型判定 → 与SYS-002标准答案对比

### 案例1：「整合资源做品牌」

**输入**：我认识一个义乌的工厂老板，他愿意给我供货价。我还有一个朋友做抖音投流的，可以合伙。我想做一个极致性价比的日用品品牌，你觉得有戏吗？

| 信号 | 提取 |
|------|------|
| 主动词 | "我想" — 未做 |
| 归因方向 | 指向外部资源（工厂老板/朋友） |
| 数据精确度 | 零数据 |
| 是否包装 | "极致性价比""品牌" — 包装空手 |

**判定**：资源幻觉型 ✓ — 工厂=别人的，投流=没签合同，品牌=不存在的

### 案例2：「飞轮效应」

**输入**：我想做一个本地生活服务的数字化平台，通过AI匹配算法连接B端商家和C端用户，第一阶段先做餐饮品类，第二阶段接入美业和健身，第三阶段做私域沉淀和数据中台，形成飞轮效应

| 信号 | 提取 |
|------|------|
| 主动词 | "我想" — 未做 |
| 归因方向 | — |
| 数据精确度 | 零数据 |
| 是否包装 | 6个高级词汇+零个动作 |

**判定**：逃避伪装成分析 ✓ — 复杂=盾，保护"还没做"

### 案例3：「50套房从3万到10万」

**输入**：在杭州做租房托管两年，50多套房稳定在管，月净利润大概3万。想从3万做到10万，但卡住了——一个人精力管50套就到顶了。应该先招帮手还是先扩展获客渠道？

| 信号 | 提取 |
|------|------|
| 主动词 | "我在做" — 已做两年 |

| 是否包装 | 描述事实 |

**判定**：正确问题 — 已做+有数据+可压缩成动作 ✓

## 二、补充验证：SYS-002缺失的3种类型

SYS-002覆盖10/13类型，以下3种需补充验证：

### 补充案例A：叙事束缚型（Type 8）

**输入**："我是清华美院雕塑系毕业的，现在负债4000万。这个债是我爸做工程失败留下的——我是替他背的。我想做短视频做IP，但我这种负债的人能出来做吗？"

| 信号 | 提取 |
|------|------|
| 主动词 | "我想做" |
| 归因方向 | 过去定义现在 |
| 数据精确度 | 4000万/清华 |
| 是否包装 | "负债=不能出来"的叙事 |

**判定**：叙事束缚型 ✓

**完整弧线**：
- **破锁**：负债4000万——你已经是岛主了——还在意什么？
- **诊断**：事实没变（清华+负债+雕塑），变的是"负债=包袱"→"负债=IP资产"
- **叙事翻转**：什么都没有可失去——冲=往上。你敢露=真实=IP——欠钱的雕塑家=短视频没做过=稀缺
- **行动路径**：今天拍第一条——对着镜头说你是谁——欠多少钱——想干嘛
- **关闭**：你的债=是你的人设——不是你的镣铐——你戴着它上战场=它变成铠甲

**覆盖类型**：Type 8 叙事束缚 ✓

### 补充案例B：多数人叙事型（Type 12）

**输入**："我团队二十多个人，90%的人都跟我说应该把那个销售主管开了——他脾气太差了，把新人都骂走了。但我说实话——他一个人贡献了我们一半的营收。团队天天跟我抱怨，我不知道该怎么办。"

| 信号 | 提取 |
|------|------|
| 主动词 | "我不知道" |
| 归因方向 | 用人数代替价值判断 |
| 数据精确度 | 20人/90%/一半营收 |
| 是否包装 | "团队说"掩盖不敢处理价值矛盾 |

**判定**：多数人叙事型 ✓

**完整弧线**：
- **破锁**：他占营收多少？50%。那你就给他磕一个吧。
- **诊断**：不是他不合群——是其他人合起来不合群。20个人90%说没用——1个人50%营收有用——你听谁的不应该看人数——应该看营收占比
- **概念区分**：数量≠正确。营收占比=唯一有效的投票
- **行动路径**：今天跟团队说——谁贡献50%营收谁说了算——你们谁能补这50%=他走——没人能=你们闭嘴
- **关闭**：有奶便是娘。商业不是民主。

**覆盖类型**：Type 12 多数人叙事 ✓

### 补充案例C：愚蠢型/该骂型（Type 13）

**输入**："大魔哥我上次问过你，你让我先去打工。我去找了一个月工作，投了三份简历没回音，算了不找了。我还是想创业——你觉得我现在做什么好？PS：我19岁。"

| 信号 | 提取 |
|------|------|
| 主动词 | "我想" — 未做 |
| 归因方向 | 指向外部（简历没回音） |
| 数据精确度 | 三份/一个月 |
| 是否包装 | — |

**判定**：愚蠢型/该骂型 ✓ — 上次答案在脸上不看+三份简历="找了一个月工作"+投三份就叫"找了"

**完整弧线**：
- **行为封喉**：上次说的做了吗——投三份简历叫找了一个月工作——你一天投了三份——剩下二十九天在干嘛——躺着
- **资格剥夺**：十九岁。没文凭。没技能。投三份简历没回音。你觉得你有资格创业吗
- **下去**：去。今天。投三十份——不是三份——三十份。有一份要你了=去上三个月班——赚到工资了=再来——没赚到=闭嘴
- **关闭**：你不是在找工作——你在等你妈给你送创业钱——她不会送的——你也不该要

**覆盖类型**：Type 13 愚蠢/该骂 ✓

## 三、自知5级完整输出样本

### L0 — 0%不自知

**输入**："我看现在AI特别火，我想做一个AI创业服务平台，帮传统企业做AI转型。我认识几个大厂的技术，他们可以兼职帮我。你觉得这个方向怎么样？"

**4信号**：主动词"我想"（未做）、归因外指（大厂技术是别人的）、零数据、包装"平台"

**自知层级**：0% — 不知道自己的东西在哪

**完整弧线**：
- **破锁**：你有什么是你自己的？没有。你认识大厂技术——他们是大厂的——不是你的人——你一台AI服务器都没跑过——一行代码没写过——你没资格问方向
- **变量压缩**：1个变量：你有没有一个客户愿意付钱？没有。那你的方向=空
- **阶段归位**：去打工。去一家AI公司——做销售——做客服——任何岗位——先知道AI公司长什么样
- **行动路径**：今天投简历。不是下周。今天。
- **关闭**：先有自己的东西——再来问方向。方向是给有筹码的人备的——你还没筹码

---

### L1 — 30%模糊自知

**输入**："我做传统建材批发的，做了四五年了利润一直在掉。这个行业不行了，我想转型但是不知道怎么转。我试过看一些新项目但是没看到合适的。"

**4信号**：主动词"我在做但"，归因外指（行业不行），模糊数据（利润在掉），有轻度包装

**自知层级**：30% — 感觉不对但归因到行业

**完整弧线**：
- **炸锁**：不是行业不行——是你没从这个行业赚到钱。做了四五年=你的客户在哪——你的老客户在做什么——他们买建材还在不在——在=行业没死——是你在死
- **归因翻转**：你试过看一些新项目——看=不叫试。试=你做了一单——赚到了钱还是亏了
- **硬锁**：你没资格问转型——你还没把建材做到天花板。你手里的老客户=你最大的资产——你不管他们=你的同行在管——你在外面看风景=后院起火
- **行动路径**：今天打十个老客户的电话——问他们还买不买——不买为什么——买的话你明天送一单
- **关闭**：行业好不好跟你没关系——你能不能在一个行业里赚到钱=跟行业好不好没关系——跟你在不在场上有关

---

### L2 — 50%自知但不动

**输入**："我做了两年亚马逊，知道问题在哪——我的选品太散了，供应链也没控住。我应该聚焦到两三个品类，然后去工厂谈独家。但一直没动——每天处理杂事，处理完就没精力去做重要的事。怎么破？"

**4信号**：主动词"我知道但"，归因内指（知道问题），中等数据，少量包装

**自知层级**：50% — 知道问题但没有行动

**完整弧线**：
- **硬锁**：你知道问题在哪。你知道解决方案。但你每天在干嘛——处理杂事。杂事=你给自己的逃跑路线——你躲在杂事里=就不用面对"去工厂谈"——因为谈工厂=可能被拒绝=你怕
- **变量压缩**：十个变量压成一个：你什么时候打第一个工厂电话？今天就打。杂事=不死的借口——你死不了也活不了
- **封死退路**：明天起——早上9点到12点——什么杂事不处理——就做一件事：找工厂——打电话——约见面。杂事下午处理。做不到=承认你不想做——别再说"我知道"——你不知道——做=知道——不做=不知道
- **行动路径**：现在拿出手机——搜一个工厂——打电话——说完你第一句话。打完了再来聊
- **关闭**："我每天处理杂事"=你的命在杂事里消耗——每一天消耗的都是你不愿面对的那个电话的时间

---

### L3 — 70%自知且委屈

**输入**："我做跨境三年了，选品选到尽头月利润就卡在三千美金。我已经很努力了——每天工作十几个小时——供应链也谈了——广告也调了——但就是冲不上去。我觉得不是我方法的问题——是品类天花板太低。"

**4信号**：主动词"我已经做了"，归因含委屈（品类天花板不是我），精确数据（3000/十几个小时），轻度包装

**自知层级**：70% — 经历过验证过但归因委屈

**完整弧线**：
- **翻锁**：你的判断对——品类确实有天花板。但你说"到了尽头"——选品到了尽头=该开品了。你不是方法不对——是阶段不对
- **诊断定位**：选品=帮别人卖——利润=是别人施舍的。开品=自己卖——利润=是你自己的。从选品到开品=从打工到创业——你在门外做了三年——门从没推开过
- **阶段归位**：三千美金=选品的尽头——开品的起点。你现在不是卡住了——是到了该换身份的时候
- **行动路径**：找一个你卖了三年最懂的品类——画一张你的产品图——找工厂报价——先做一个样品——放在你现在最好的listing上——测一周——看数据。不是广告的问题——是"你没有一个东西是自己的"的问题
- **关闭**：三千美金=三年的学费。不是亏损——是学费。学费交完了——该开店了——不是换店——是开你自己的店

---

### L4-L5 — 90%+清醒

**输入**："我做了五年本地生活服务，现在月利润稳定在15万左右。我下一步想从服务商升级成咨询公司——帮其他城市的团队复制我这套打法。我分析了三个城市的数据，觉得可行，但不确定是先验证一个城市深度做，还是同时铺三个城市。你帮我看看。"

**4信号**：主动词"我已经做了"，归因内指，精确数据（15万/五年/三个城市），无包装

**自知层级**：90%+ — 带分析不绑死，已做有数据

**完整弧线**：
- **软锁**：你的思路没问题。五年+15万+三个城市数据——不是凭空想的
- **确认+加保**：先验证一个城市。不要同时铺三个——路径太长——你不知道跨城市复制会遇到什么——在第一个城市踩完坑——第二个城市才快
- **细化**：选最小最快的城市——不是最大的——最小的跑通了——方法论才成立——最大的可能吃下但你没验证过
- **行动路径**：这个月内选一个城市——你人过去——待两周——签约三个客户——回来。跑通了=你的咨询公司有了第一张案例——用案例说话不是用数据说话
- **关闭**：方向对。阶段对。节奏调一下——先验证再扩——不差三个月
