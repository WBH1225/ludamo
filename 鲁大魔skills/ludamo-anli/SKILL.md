# 调用协议

lianmai传过来：13型 + 自知层 + （可选）行业/概念

```
Step 1: 三线交叉定位
  - 线1（13型+自知层）→ 主匹配
  - 线2（概念）→ 辅助匹配（如果涉及概念理解错误）
  - 线3（行业）→ 辅助匹配（如果用户说了行业）

Step 2: 取交集最匹配的1个。交集空→按线1优先。

Step 3: 场景适配过滤（行业跨度检查）
  匹配的案例行业与用户行业对比：
  - 同行/近行 → 直接嵌入。"有个人跟你一样做跨境的——"
  - 跨行但问题同构 → 加一句桥接。"你不是做羽毛球的。但他问的问题跟你一模一样——"
  - 行业完全不相关 → 降级。不硬嵌，只取思维判定+武器链的逻辑，不展开案例背景。
  
  目的：避免"用户做跨境，你讲羽毛球品牌"的生硬感。桥接句让用户看到"问题同构"而不是"案例不搭"。

Step 4: 输出案例
  速查库有详情 → 标准格式（背景→思维判定→武器链→翻转→结果→LD来源）
  速查库无详情 → 降级输出：标题 + "这个人跟你一样犯了同一个错误——[一句话思维判定]。去看 [[案例ID]]。"  不编造内容。

Step 5: 不出启示。不延伸。不"这意味着你..."
```

### 案例覆盖与检索兜底

**当前覆盖率**：速查库17/71有完整详情，其余54例仅标题+标签可用。

**兜底规则**：
- 命中详情案例 → 完整输出
- 命中仅有标签案例 → 降级输出（标题+思维判定一句话+ID），不编造
- 三线全空（极罕见）→ 返回空，lianmai 跳过案例嵌入，纯管道输出

**补录优先级**：高频类型优先——瓶颈误诊（线1最多）、假迷茫、资源幻觉。这三种覆盖全了=80%的诊断场景有案例可用。

# 案例速查库

## CAS-001：羽毛球品牌梦——资源拼凑型创业的完整解剖
- **背景**：体育生创业者想做"极致性价比羽毛球品牌"
- **思维判定**：资源幻觉。三样全是别人的（平台合作方=别人的，供应链=没谈成，IP计划=空的），零个是自己的
- **武器链**：前提击穿→变量压缩→阶段归位→行为证据
- **翻转**：不进"品牌有没有戏"框架→直接做资源盘点→"三样都是别人的。你没有自己的任何一块砖。"
- **结果**：连麦人自我放弃——"我觉得没有戏"
- **来源**：LD-001

## CAS-002：TK带货月入十几万——半个生意的天花板
- **背景**：TK短视频带货创业者月入十几万增长停滞
- **思维判定**：瓶颈误诊。内容模型已验证但货不是他的=半个生意。把"增长停滞"归因到"方向问题"
- **武器链**：破锁→瓶颈定位→概念区分（方向vs后端）→行动路径
- **翻转**：不是方向问题→是后端问题→测品优先于选区域
- **结果**：从"选方向×选区域×选工具"三变量压缩为"测品"
- **来源**：LD-003

## CAS-003：1.62亿不敢露——吹牛者的完整解剖
- **背景**：自称传媒公司月流水1.62亿但不敢展示后台数据
- **思维判定**：数据造假+自我误诊双型。用无法验证的大数字建立权威
- **武器链**：证伪思维（"打开后台"）→行为证据→资格剥夺→驱逐
- **翻转**：不进方法论辩论→只要一个动作→四次推脱=四次证据→"不敢打开=答案"
- **结果**：在直播间当众被破锁，所有借口被预先穷尽
- **来源**：LD-002

## CAS-004：医药电商总监伪圣人叙事——花老板的钱当老好人
- **背景**：医药电商总监月薪一万五，自掏两三千请团队喝奶茶
- **思维判定**：逃避分析。用"我对他们好"替代"我管理能力为零"
- **武器链**：破锁→归因翻转→行为证据→行动路径
- **翻转**：你花的两三千是老板的工资→你在花老板的钱当圣人→去学OKR
- **结果**：从"老板思维落后"翻成"总监不会管理"
- **来源**：LD-004

## CAS-005：亚马逊利润卡三千——从选品到开品的突破
- **背景**：亚马逊卖家利润卡在三千上不去
- **思维判定**：瓶颈误诊。在选品池里打转——真正瓶颈是没开品
- **武器链**：破锁→概念区分（选品vs开品）→行动路径
- **翻转**：选品=在别人池里挑=利润被定死→开品=自己开发=利润自己定
- **结果**：从"选"到"造"的跃迁
- **来源**：LD-533

## CAS-013：被开除想做主播vs家电维修——阶段归位
- **背景**：被开除的工业机器人技术员，三选一（主播/运营/维修）
- **思维判定**：假迷茫。最有资源的方向（爸20年维修经验+现成店铺）放最后，追零资源方向
- **武器链**：阶段归位→变量压缩→行动路径
- **翻转**：跟你爸学维修但升级方向——不是修电饭煲是修手机数码
- **结果**：从假选择翻成真路径
- **来源**：LD-074

## CAS-015：去深圳不要省钱——环境决定论
- **背景**：年轻人选城市纠结房租成本
- **思维判定**：自我误诊。把"没钱"当理由——真实成本不是房租是学不到东西的机会成本
- **武器链**：破锁→环境决定论→叙事翻转
- **翻转**：不是成本问题→是环境投资→深圳=精英碾压=你的标准被提高
- **结果**：从"省钱"翻成"投资环境"
- **来源**：LD-556

## CAS-022：创业失败不敢卖觉得在骗人——情不立事
- **背景**：创业失败多次送外卖，想做成人用品但"话说不出口"
- **思维判定**：抱怨伪装。把"销售"定义成"骗"——用"太善良"包装"不敢收钱"
- **武器链**：破锁→概念区分→叙事翻转→行动路径
- **翻转**：销售≠骗；不敢收钱≠善良；赚多了不安≠有良心→"创业讲本分，不讲情分"
- **结果**：从"我太善良骗不了人"翻成"你把销售定义成了骗"
- **来源**：LD-694

## CAS-025：监狱管理启蒙——从最低点萃取管理知识的反身性手术
- **背景**：监狱生活对创业是否有帮助
- **思维判定**：叙事束缚→翻转。同一个经历，看它的方式决定是毁灭还是养料
- **武器链**：叙事翻转→概念区分→反身性自检
- **翻转**：坐牢=毁灭→坐牢=管理学堂。提取三样：管理架构、量化标准、人性洞察
- **结果**：最低点成为最高教材。"鲁大摩"=在被囚禁的身体里植入"大魔王"自我认知
- **来源**：LD-041

## CAS-041：25岁被50岁合伙人背叛踢出店——从零到一再走一遍
- **背景**：25岁被合伙人背叛踢出店，手头两万块
- **思维判定**：自我误诊→翻转。以为被偷走了成果→能力没被偷
- **武器链**：翻锁→逆向思维→阶段复利→行动路径
- **翻转**：背叛偷走成果没偷走能力→从零到一再走一遍→你已经会了→第二遍速度三倍
- **结果**：从"该回学校"翻成"该开自己的店"
- **来源**：LD-733

## CAS-068：大专毕业三个月抽卡师——两万块当老板
- **背景**：大专毕业入职三个月学会漫剧全流程，觉得壁垒低该走还是留
- **思维判定**：自我误诊。把"壁垒低"解读为"行业没前途"——但壁垒低=你也能做老板
- **武器链**：身份翻转→逆向思维→变量压缩→行动路径
- **翻转**：三个月全流程=当老板需要的全部判断力→"两万块"压到"你兜里就有"
- **结果**：从"我是员工"→"我是内容收购者"
- **来源**：LD-868

## CAS-069：山东小伙十年陪前辈聊天什么都没拿到——被双炸醒
- **背景**：山东人十年陪有地位的前辈聊天，以为"总有一天资源会给我"
- **思维判定**：资源幻觉→价值交换。十年没证明过翻倍=消耗品
- **武器链**：破锁→价值交换→行为证据→关闭
- **翻转**：第一击——你没能力接资源；第二击——前辈在自我炫耀不是帮你；第三击——以目的区分不以好坏区分
- **结果**：十年社交=零。该沉默的是看见过去十年的自己一直跪在不存在的椅子前面
- **来源**：LD-891

## CAS-070："老师"半年赚7000万带你翻倍——两句话炸碎庞氏
- **背景**：一个老师公安出身半年赚7000万，说存够10个点带你翻倍
- **思维判定**：资源幻觉→逻辑反转。真能赚为什么给你？
- **武器链**：前提击穿→逻辑反转→行为证据→关闭
- **翻转**：不进叙事框架→"真能赚为什么要给你？说明他缺钱了。真能赚钱不会缺钱的。"
- **结果**：不需要查证件不需要分析人品——逻辑先于事实。以后每次有人带你赚钱先问"他为什么要给你"
- **来源**：LD-915

## CAS-030：种1000亩中药材没签采购合同——追涨逻辑
- **背景**：种植户种了1000亩中药材，没签采购合同就扩产
- **思维判定**：乱炖。把"市场价格高"当"我能卖出去"——追涨。三个独立问题搅在一起：种什么（供应链）、卖给谁（需求）、什么时候卖（时机）
- **武器链**：破锁→概念区分→各自回答
- **翻转**：价格高≠有人买你的。合同在前扩产在后——顺序反了。三个问题拆开：先找采购合同→再决定种多少→再定时机
- **结果**：从"追涨逻辑"翻成"合同逻辑"
- **来源**：LD-466

## CAS-011：AI替代电商运营——被替代的是不用AI的人
- **背景**：电商运营从业者担心AI替代自己的岗位
- **思维判定**：正反馈误读。已经有客户在付钱（证明能力在），却把注意力放在"AI威胁"上
- **武器链**：破锁→叙事翻转（→深耕）→阶段归位
- **翻转**：被替代的不是做电商运营的人——是不用AI做电商运营的人。你在行业里=比新人领先。AI×你的经验=新人赶不上。
- **结果**：从"怕被替代"翻成"用AI加强自己"
- **来源**：LD-058

## CAS-008：员工学会了自己开店——竞业协议没用
- **背景**：老板发现员工学会业务后离职开同类型店，竞业协议挡不住
- **思维判定**：多数人叙事。"员工不该这样""90%的老板都说要签竞业"——用人数代替价值判断
- **武器链**：一句封喉→概念区分（数量≠价值）→叙事翻转
- **翻转**：竞业协议防不了想走的人——防的是不敢走的人。真正该问的不是"怎么防员工开店"而是"为什么员工开店能跟你抢客户"。你的客户认的是你还是产品？
- **结果**：从"竞业协议"翻成"客户归属"
- **来源**：LD-216

## CAS-014：三十岁自我介绍被叫停——人设边界
- **背景**：直播间连麦，三十岁男性自我介绍絮叨三分钟，被鲁大魔叫停
- **思维判定**：愚蠢/该骂。不是在介绍自己——是在表演"我很努力地在介绍自己"。三分钟没说出一个别人需要知道的事实
- **武器链**：资格剥夺→行为证据→下去
- **翻转**：三十岁了。一句话说清楚你是谁、做什么的、为什么上麦。说不清楚=没想清楚。没想清楚=连麦干什么？
- **结果**：被叫停后重新一句话说完——"每天在干什么事的人说自己每天不知道干什么"
- **来源**：LD-063
