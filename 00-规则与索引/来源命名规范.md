# 来源命名规范

## 来源 ID 结构

统一使用：

`SRC-类别代码-序号`

例如：

- `SRC-WX-001`
- `SRC-VIDEO-011`
- `SRC-BK-002`

## 类别代码建议

- `WX`：公众号文章
- `VIDEO`：短视频文稿
- `BK`：爆款文稿
- `CON`：观点与概念素材
- `EXT`：外部研究素材
- `USER`：用户本人其他素材

## 规则

- 同一路径一旦分配来源 ID，不重复分配
- 旧 ID 已经被内容单元使用时，不随意改号
- 批量脚本生成的是候选表，正式以 `来源注册表.csv` 为准
