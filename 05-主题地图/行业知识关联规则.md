# 行业知识关联规则

> 同一个行业内的知识点是怎么串联的。回答："在电商/创业/管理这个行业里，知识点的连接规律是什么？"

---

## 规则1：电商 —— 供应链决定论

**核心关联链：**

```
流量模型已验证 → 增长停滞 → 瓶颈不在前端 → 货不是你的 → 利润被供应链锁死
                                                        ↓
                                              纯带货=半个生意=天花板
                                                        ↓
                                              测品→控货→完整生意
```

**关键节点：**
- 起点：[[QST-002_增长瓶颈被误诊为方向问题|QST-002]]（增长瓶颈被误诊为方向问题）
- 翻转：[[OPI-002_电商真正赚钱的都是做供应链的|OPI-002]]（电商真正赚钱的都是做供应链的）
- 案例：[[CAS-002_TK带货月入十几万——半个生意的天花板|CAS-002]]（TK带货月入十几万——半个生意的天花板）
- 解法：[[SOL-002_测品优先于选区域——电商增长的正确顺序|SOL-002]]（测品优先于选区域）

**关联规则：** 电商领域任何"增长停滞"问题，第一检查点不是前端（内容/流量/渠道），是后端（供应链/控货）。利润流向控制后端的人——这是电商行业不变的结构。方向/区域/平台都是表面变量，供应链是根变量。

**适用场景：** 带货/跨境电商/品牌电商的所有增长类问题

## 规则2：创业判断 —— 资源盘点先于项目评估

**核心关联链：**

```
我有一个商业计划 → 问"有没有戏" → 不进项目评估 → 先做资源盘点
                                            ↓
                              你的 vs 别人的 / 已完成的 vs 已计划的
                                            ↓
                              零个是自己的 → 你还没到能问这个问题的阶段
                                            ↓
                              先有你自己的一个东西 → 再谈第二块
```

**关键节点：**
- 起点：[[QST-001_资源拼凑型创业者的可行性错觉|QST-001]]（资源拼凑型创业者的可行性错觉）
- 概念：[[CON-001_老登——行业存量玩家的行为逻辑|CON-001]]（老登——行业存量玩家的行为逻辑）
- 翻转：[[OPI-001_你没有自己的东西之前任何商业计划都是泡沫|OPI-001]]（你没有自己的东西之前任何商业计划都是泡沫）
- 案例：[[CAS-001_羽毛球品牌梦——资源拼凑型创业的完整解剖|CAS-001]]（羽毛球品牌梦）
- 解法：[[SOL-001_从零到一——先有你自己的一个东西|SOL-001]]（从零到一——先有你自己的一个东西）

**关联规则：** 创业判断的第一步不是评估项目，是盘点资源。区分两对概念：你的vs别人的、已完成的vs已计划的。老登法则补了一刀：任何品牌最终都要过供应链→供应链在老登手里→你不是在创业，你是在给老登打工。所以创业判断=资源盘点+老登位置判断。

**适用场景：** 所有"我有一个idea/project，你觉得行不行"类问题

## 规则3：团队搭建 —— 漏斗替代精准

**核心关联链：**

```
业务做起来了 → 想搭团队 → 问"从哪招人好" → 不进渠道问题
                                    ↓
                        招人=概率游戏 → 精准命中=不尊重概率
                                    ↓
                        人力漏斗：大量招聘→工作试用→结果筛选→持续循环
                                    ↓
                        漏斗不能加速 → 接受慢=管理能力
```

**关键节点：**
- 起点：[[QST-004_想快速搭团队但不理解人力漏斗|QST-004]]（想快速搭团队但不理解人力漏斗）
- 概念：[[CON-003_人力漏斗——团队搭建的系统流程|CON-003]]（人力漏斗——团队搭建的系统流程）
- 翻转：[[OPI-004_团队是漏斗筛选出来的不是一次招到的|OPI-004]]（团队是漏斗筛选出来的不是一次招到的）
- 解法：[[SOL-004_招聘漏斗四步法——从大量招聘到持续循环|SOL-004]]（招聘漏斗四步法）

**关联规则：** 有业务能力的创始人最容易在团队上栽跟头——把单点能力误认为系统能力。团队搭建的陷阱在于"以为找对人=搭好团队"。"找对人"思维让你挑三拣四→永远找不到。"筛出人"思维让你建系统→系统自动产出。正常比例招10留2——接受这个比例本身就是管理成熟度。

**适用场景：** 初创团队/从0到1团队的所有招聘困境

## 规则4：焦虑/专注力 —— 环境决定论

**核心关联链：**

```
赚钱后空虚 → "我废了/没能力了" → 不进身份框架 → 这是两个可诊断的症状
                                            ↓
                        闲置时间太多 + 无法深度专注 = 城市生活方式病
                                            ↓
                        焦虑不可消除 → 但可被专注覆盖 → 需要被迫专注的环境
                                            ↓
                        自驾旷野 → 开车时最专注 → 旷野时间流速慢 → 重置
```

**关键节点：**
- 起点：[[QST-003_赚钱后失去专注力的身份危机|QST-003]]（赚钱后失去专注力的身份危机）
- 概念：[[CON-002_焦虑覆盖原理——焦虑不可消除但可被专注覆盖|CON-002]]（焦虑覆盖原理）
- 翻转：[[OPI-003_不是人废了是城市生活方式剥夺了专注力|OPI-003]]（不是人废了是城市生活方式剥夺了专注力）
- 解法：[[SOL-003_自驾旷野——用被迫专注重置时间感知|SOL-003]]（自驾旷野——用被迫专注重置时间感知）

**关联规则：** 成功后焦虑的特殊性在于——它不是"不够好"的焦虑，是"够了但不知道接着干什么"的焦虑。这种焦虑不能用"更努力"解决——因为方向已经没了。鲁大魔不用心理治疗框架——用物理干预。核心逻辑：不是治焦虑，是创造焦虑无法生存的环境。城市=焦虑的温床（不需要你专注），旷野=焦虑的禁地（被迫专注）。

**适用场景：** 成功后空虚/创意工作者倦怠/所有"做什么都提不起劲"的状态
