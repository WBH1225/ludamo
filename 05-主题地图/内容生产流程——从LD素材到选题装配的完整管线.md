# 内容生产流程

## 总流程：四阶段管线

```
[阶段1: 素材层]           [阶段2: 单元层]           [阶段3: 装配层]           [阶段4: 发布层]
                                                                                    
原始LD文件                内容单元(CON/OPI)          选题装配稿                 短视频/文章/口播
    │                         │                         │                         │
    ├─ 904条对话              ├─ 26 CON                ├─ 选题=QST+OPI+CON       ├─ 钩子（前3秒）
    ├─ 904条拆解              ├─ 22 OPI                ├─ 骨架=概念链             ├─ 翻转（第2段）
    ├─ 185条非拆解            ├─ 11 QST                ├─ 血肉=LD原话             ├─ 价值拉升（第3段）
    │                         ├─ 5 SOL                 ├─ 收口=行动召唤           ├─ 信任破壁（第4段）
    │                         └─ 4 CAS                 │                         └─ 收口（最后3秒）
    │                         │                         │
    ▼                         ▼                         ▼
  筛选                      关联                      重组
  (自知/权重/锁型)           (关系/去重/冲突)          (主题地图引导)
```

---

## 阶段1：素材层 → 筛选

**输入**：904条LD原始文件

**筛选维度**：

| 维度 | 筛选项 | 用途 |
|------|-------|------|
| 自知等级 | 0%/30%/50%/70%/100% | 破锁→钩子素材；翻锁→教学素材 |
| 权重 | ⭐5-15 | 高权重优先提取 |
| 锁型 | 破/炸/硬/翻/软 | 匹配目标受众的情绪状态 |
| 路线 | 拆解/表演/反身/边界声明 | 拆解→问题诊断内容；表演→框架教学 |
| 标签 | 供应链/AI/流量/获客… | 匹配目标主题 |

**快速筛选口诀**：
- 做钩子→找0%自知+破锁+高冲突
- 做教学→找70%自知+翻锁+框架植入
- 做金句→找L2核心判断+原句高密度
- 做案例→找100%自知+真实数据+完整路径

---

## 阶段2：单元层 → 抽取

**从筛选后的LD中抽取内容单元**：

```
一篇LD → 抽取判断：
  ├── 有新问题框架？→ QST（问题单元）
  ├── 有可独立传播的观点？→ OPI（观点单元）
  ├── 有稳定定义/可迁移概念？→ CON（概念单元）
  ├── 有具体事件/数据/完整故事？→ CAS（案例单元）
  └── 有明确动作路径？→ SOL（方案单元）
```

**单元创建检查清单**：
- [ ] source_documents 指向原始LD
- [ ] core_claim/concept_definition 一句话可独立传播
- [ ] relationships 与现有单元建立连接
- [ ] keywords 6个标准化关键词
- [ ] themes 至少2个主题标签

## 阶段3：装配层 → 重组

**从内容单元重组为选题装配稿**：

### 装配公式

```
选题装配稿 = 一个QST + 1-2个OPI + 1-2个CON + （可选）CAS + （可选）SOL
```

### 装配骨架（对应dbs_deliverables的7步提问链结构）

| 段落 | 功能 | 来源 | 时长占比 |
|------|------|------|---------|
| 钩子 | 戳痛点/反常识 | QST的核心问题 | 10% |
| 翻转 | 打破旧认知 | OPI的core_claim | 25% |
| 框架 | 建立新认知 | CON的concept_definition | 25% |
| 证据 | 数据/案例支撑 | CAS + LD原话 | 20% |
| 价值拉升 | 从技巧到认知升级 | CON+OPI的why_it_matters | 15% |
| 收口 | 自然召唤（不叫卖） | SOL的动作路径 | 5% |

### 装配检查清单
- [ ] 选题有一个明确的QST锚点
- [ ] 骨架沿概念链展开（不跳步）
- [ ] 每个观点有LD原话支撑
- [ ] 收口=行动召唤≠叫卖
- [ ] 全篇可独立传播（不依赖读者看过其他内容）

## 阶段4：发布层 → 多平台适配

### 平台-格式映射

| 平台 | 时长/篇幅 | 结构重点 | 钩子策略 |
|------|---------|---------|---------|
| 抖音 | 2-3分钟 | 钩子+翻转+金句 | 反常识爆破 |
| 视频号 | 3-5分钟 | 钩子+框架+证据+收口 | 共鸣型 |
| 小红书 | 800-1500字 | 钩子+翻转+清单化 | 结果承诺型 |
| 公众号 | 1500-3000字 | 完整装配骨架 | 痛点共鸣 |

### 鲁大魔特色发布原则

1. **内容先行**：先拍高端素材→再直播→再私域。顺序不能反。
2. **表演即教学**：让人看见你怎么想>告诉他怎么想。展示思维过程>展示结论。
3. **1000人逻辑**：不求大流量，求1000个真客户。精准>规模。
4. **不辩论只验证**：内容不跟风不争论不蹭热点。只展示验证过的东西。

## 完整示例：咖啡豆选题的装配追踪

```
[阶段1] 筛选 → LD-157 (⭐12, 70%自知, 翻锁, 咖啡豆品牌)
[阶段2] 抽取 → QST: "品类决定销售渠道" / OPI: "直播不是万能渠道" / CON-022: 渠道匹配律
[阶段3] 装配 → 
    钩子："你是不是也在直播间卖不动？问题不在你——在你的品类根本不合适直播。"
    翻转：咖啡豆≠直播带货品→在沃尔玛摆精品咖啡摊
    框架：品类决定渠道三轴（公域直播/私域+内容/平台直连）
    证据：LD-157十个月无效直播+鲁大魔原话
    价值拉升：不是流量问题——是品类认知问题
    收口："第一步，搞清楚你的品类该去哪。如果需要，找我聊聊。"
[阶段4] 发布 → 抖音2分30秒版（反常识爆破型钩子）
```

## 批量生产SOP

**从"一篇一篇写"到"管线流水线"**：

1. **筛**：从904 LD中按自知+权重+标签筛选10-20条
2. **抽**：每条LD抽取2-3个单元（QST+OPI+CON）
3. **关**：与现有单元建立关系→去重检查
4. **装**：选2-3个同主题单元装配为一篇选题稿
5. **发**：按平台适配格式输出

**管线吞吐量估算**：一轮管路（筛10条→抽20-30单元→装5-8篇选题稿）= 约2-3小时AI工作。
