# 系统关系矩阵

## 说明

本矩阵覆盖三条核心关系轴：
- **轴A：QST→OPI** — 哪类问题用哪个观点诊断
- **轴B：QST→CON** — 哪类问题需要哪个概念解释
- **轴C：CON→CON** — 概念之间的依赖/扩展链

不枚举frontmatter中已有的全部关系（见`generate-link-map.js`输出），只列结构性关系。

