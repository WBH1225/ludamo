# 拆解模板与连麦管道的衔接

> 两个系统共享五闻四锁但定位不同。本文档说明离线拆出来的规律怎么喂给实时管道。

---

## 一、两个系统的定位

| | 拆解模板（离线） | 连麦管道（实时） |
|----|---------------|---------------|
| **文件** | `04-模板/拆解模板-对话分析.md` | `鲁大魔skills/ludamo-lianmai/SKILL.md` |
| **输入** | 已录制的直播片段，含完整上下文 | 用户实时打字，信息零散 |
| **时间** | 无限制——逐条穷尽拆解 | 0.5秒自知判断→秒级回应 |
| **产出** | 完整的L1-L5+五闻四锁+跨条连接 | 一段鲁大魔式自然对话 |
| **使用者** | 知识库构建者（人+AI协作） | AI诊断管道（全自动） |
| **目标** | 穷尽拆解→提取规律→喂给管道 | 判思维对不对→不对就拉→给答案 |

---

## 二、离线→实时的四条喂养链路

### 链路1：自知光谱的精确化

**离线做了什么**：904条对话逐条标注自知%，统计出六层分布（0%=10.4%, 30%=23.1%, 50%=34.4%, 70%=22.6%, 90%+=8.8%）。

**喂给实时管道什么**：
- 4信号→自知%的映射已精确到百分比（`awareness-spectrum.md`）
- 最大群体50%→变量压缩+锁扣锻造双管齐下
- 10.4%的0%自知→直接破锁不回答（管道不需要浪费算力分析）

**管道里的体现**：`ludamo-lianmai/SKILL.md` L0五闻→4信号→自知锚定，这条链的权重和阈值来自离线统计。

### 链路2：13型×武器链的匹配表

**离线做了什么**：904条逐条标注问题类型（13型）、映射编号（1-9）、手段编号（1-9）、信念编号（1-7）。统计出每种类型的最高频武器组合。

**喂给实时管道什么**：
- 13型×武器组合的速查表（`ludamo-lianmai/SKILL.md` "武器链速查"）
- 每种类型的第一刀/第二刀/第三刀/关闭——来自离线统计的最高频组合拳

**管道里的体现**：管道判定13型后直接查表选武器，不需要重新推理。

### 链路3：锁型力度的校准

**离线做了什么**：904条逐条标注锁型（破锁114/炸锁236/硬锁215/翻锁229/软锁101），统计锁型×自知%的精确对应。

**喂给实时管道什么**：
- 自知0%→破锁（80%概率），不自知到一定程度只能宣告
- 自知30%→炸锁（70%概率），需要强力打断
- 自知50%→炸锁或硬锁（60%+30%），需要变量压缩+封死退路
- 自知70%→翻锁（50%概率），先共情再翻转
- 自知90%+→软锁（70-80%概率），确认+加保

**管道里的体现**：`ludamo-lianmai/SKILL.md` "锁型匹配"段的精确比例来自离线统计。

### 链路4：物锚点的验证

**离线做了什么**：904条对话新增物锚点（行为事实+语法事实+偏离度），把"鲁大魔的判断"锚定到"可验证的物理事实"。

**喂给实时管道什么**：
- `ludamo-lianmai/SKILL.md` 新增的"骂前事实锚定"——骂之前快速锚定检查
- 语法事实的典型模式（"我被X困住"→"我选了不行动"）→实时管道识别被动句后自动触发主语归位
- 偏离度反比锁型力度——偏离越大锁型越狠

**管道里的体现**：闻4语法嗅觉→自动提取被动句→主语归位，这条能力来自离线对627条有被动句的对话的语法分析。

## 三、管道跑偏时的回溯路径

当实时管道输出质量下降时，回到离线拆解模板检查：

| 管道症状 | 回溯到离线查什么 | 具体操作 |
|---------|---------------|---------|
| 自知%判断偏了 | 对比同类问题的离线自知标注 | 从 `904连麦用户全量蒸馏` 找同嘴型案例，对照自知% |
| 锁型力度不对 | 查离线锁型×自知交叉统计 | 从 `鲁大魔解决问题方法论` 对照该自知层的标准锁型分布 |
| 武器选错了 | 查13型×武器组合速查表 | 对照离线最高频组合拳 |
| 拉出层次不够 | 查同类问题的L1-L5完整拆解 | 从对话库搜同类案例的L5层，看离线怎么拉到底的 |
| 骂了但没锚到事实 | 查物锚点的行为事实 | 管道"骂前事实锚定"不通过→先追问不骂 |

## 四、离线新增规律→管道更新的触发条件

不是每次离线发现都要改管道。触发条件：**同一模式在离线分析中出现≥10次**。

| 发现类型 | ≥10次触发 | 更新管道的什么 |
|---------|----------|--------------|
| 新"嘴型"（同一问题的不同问法） | 触发 | 追加到13型判定的"核心信号"列 |
| 新武器组合 | 触发 | 追加到武器链速查表 |
| 新自知层变体（如20%/40%/60%/80%） | 触发 | 追加到自知光谱的细分档 |
| 新被动句模式 | 触发 | 追加到闻4语法嗅觉的识别库 |
| 单条独特案例 | 不触发 | 只入库anli，不改管道 |
