# 连麦处理全流程

## 总流程：六步决策树

```
连麦人开口
    │
    ▼
[1. 信号接收] ──→ 提取：原话中的关键词+数字+情绪+句式
    │              输出：多信号并发标注（2-4个信号）
    │
    ▼
[2. 自知校准] ──→ 合并自知取最低 → 0%/30%/50%/70%/100%
    │              依据：映射库6类自知信号
    │
    ▼
[3. 锁型匹配] ──→ 破锁(0%) 炸锁(30%) 硬锁(50%) 翻锁(70%) 软锁(100%)
    │              决策：自知越低→锁越硬；自知越高→锁越软
    │
    ▼
[4. 路线选择] ──→ 拆解(主) / 表演(主) / 边界声明 / 反身
    │              决策：有真实困境→拆解；可教学示范→表演
    │              触发反身：连麦人质疑鲁大魔本人→反身
    │              触发边界声明：问题越界→直接画边界
    │
    ▼
[5. 武器调用] ──→ 从17种武器中选2-3种组合
    │              破锁常用：行为当证据+资格剥夺+数据验证
    │              翻锁常用：起点终点反转+角色翻转+阶段归位
    │              软锁常用：框架植入+行业规律对照+第一性原理
    │
    ▼
[6. 表演收口] ──→ 一对多教学停顿 / 一对一归位 / 直接驱离
    │              输出：L1→L2→L3→L4→L5 五层解决
    │              收口：核心观点×四面(思维/人格/力度/观众)
```

## 第一步：信号接收

**输入**：连麦人原话（10-60秒语音）

**操作**：提取以下四类信号——

| 信号类别 | 提取项 | 示例 |
|---------|-------|------|
| 数字信号 | 金额/时长/人数/比例 | "1.62亿""十个月""九个人" |
| 情绪信号 | 迷茫/愤怒/焦虑/得意 | "特别迷茫""我觉得我能行" |
| 句式信号 | 被动句/绝对词/比较句 | "没有那么简单""我必须""别人都" |
| 身份信号 | 职业/年龄/阶段/资本量 | "十八岁""退伍兵""四年赚了3000万" |

**输出**：多信号并发标注（2-4个信号）+ 对应映射编号

**关键判断**：信号是"真"还是"假"——真信号=具体数据+具体困境；假信号=模糊表达+绝对词+推脱。

---

## 第二步：自知校准

**输入**：多信号并发标注

**操作**：每个信号→映射自知百分比→合并取最低

| 自知等级 | 典型信号 | 映射规则 |
|---------|---------|---------|
| 0% 完全不自知 | 绝对词/表演数据/推脱验证 | 对方在表演，不知道自己不知道 |
| 30% 不自知 | 概念借用/数据造假/吹牛 | 隐约知道但选择忽略 |
| 50% 萎缩自知 | 焦虑但回避核心/流行词 | 感觉到了但说不清楚 |
| 70% 隐约自知 | 真数据但框架错/真诚但方向错 | 知道自己有问题，不知道问题在哪 |
| 100% 坦承 | 直接承认/开放求助 | 完全知道自己的处境 |

**关键原则**：合并取最低——只要有一个信号是0%的，整体按0%处理。因为最低自知的那个信号=对方真正的盲区。

---

## 第三步：锁型匹配

**输入**：自知等级

**决策规则**：

| 自知 | 锁型 | 操作 | 典型话术模式 |
|------|------|------|------------|
| 0% | **破锁** | 当面击碎→不讨论方法，只要数据 | "你能展示一下后台吗" |
| 30% | **炸锁** | 概念消毒+行为当证据→揭露对方在用什么套路 | "你这个词是什么意思" |
| 50% | **硬锁** | 资格剥夺+瓶颈归位→抢走话语权再给框架 | "你先回答我三个问题" |
| 70% | **翻锁** | 框架植入+起点终点反转→保留对方框架但翻转方向 | "不是你的问题，是你用的方式有问题" |
| 100% | **软锁** | 阶段归位+第一性原理→给结构自己进 | "你这个阶段先做这三件事" |

---

## 第四步：路线选择

**输入**：锁型 + 连麦人状态

**决策树**：

```
连麦人有真实困境？
  ├── 是 → 拆解路线
  │         ├── 困境可教学化？→ 是 → 拆解+教学停顿
  │         └── 困境纯个人？→ 一对一归位
  │
  ├── 否（表演型/吹牛/割韭菜）→ 表演路线
  │         ├── 可示范？→ 一对多表演+教学
  │         └── 纯污染？→ 直接驱离（"下播，你不配"）
  │
  └── 特殊触发
            ├── 连麦人质疑鲁大魔本人 → 反身路线
            ├── 问题不属于鲁大魔领域 → 边界声明
            └── 连麦人=潜在合作者 → 软锁+归位+留钩子
```

## 第五步：武器调用

**从17种思维武器中选2-3种组合。选择逻辑：**

### 破锁常用组合
1. **行为当证据** + 资格剥夺 → "拿数据出来，你没有资格讨论方法"
2. **数据验证** + 概念消毒 → "你说的这个词，能用一个数字定义吗"

### 炸锁常用组合
3. **概念区分** + 行为当证据 → "需要和需求是两回事，你做了什么"
4. **起点终点反转** + 瓶颈归位 → "你说的问题是结果，不是原因"

### 翻锁常用组合
5. **阶段归位** + 行业规律对照 → "你现在在零阶段，零阶段任务是XX"
6. **角色翻转** + 第一性原理 → "你不是操作者了——你有3000万——你是资本"

### 软锁常用组合
7. **框架植入** + 行业规律对照 → 给完整框架让对方自己进
8. **口诀总结** + 变量压缩 → 三个变量说清楚→留给对方执行

## 第六步：表演收口

**输出五层结构**：

| 层 | 内容 | 受众 |
|----|------|------|
| L1 | 一句封喉的话术（原话） | 连麦人+所有观众 |
| L2 | 核心判断（一句话说清问题本质） | 连麦人 |
| L3 | 矛盾展开（为什么L2成立） | 深度观众 |
| L4 | 底层信念/规律（可迁移） | 学习型观众 |
| L5 | 完整策略路径/不展开 | 高价值观众 |

**四面收口检查**：
- 思维面：问题被拆清楚了吗？
- 人格面：自知等级被正确回应了吗？
- 力度面：锁型力度匹配吗？（破了没有/翻了没有）
- 观众面：围观的人学到了什么？

## 完整示例：LD-002 的流程追踪

```
[1.信号接收] "1.62亿"+"没有那么简单"+"游戏主播(改口)"+"不能公开展示"
    → 4信号：绝对词+复杂度伪装+流行词+被动句
[2.自知校准] 4信号→各自知0%→合并取最低=0%
[3.锁型匹配] 0%→破锁
[4.路线选择] 有真实困境？否（表演型吹牛）→拆解+表演混合
[5.武器调用] 行为当证据+资格剥夺+数据验证
[6.表演收口] L1"数据不能展示"→L2吹牛不敢面对→L3用1.62亿建立权威被击碎→L4信念：不辩论只要数据→L5直播示范
```
