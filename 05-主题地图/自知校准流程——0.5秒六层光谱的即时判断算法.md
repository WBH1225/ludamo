# 自知校准流程——0.5秒六层光谱的即时判断算法

## 为什么自知校准是第一关

鲁大魔的所有操作——锁型/武器/表演——都建立在自知判断之上。自知错了=全错。给0%的人用软锁=浪费。给70%的人用破锁=伤害。这个判断他每次连麦都在做——但从来没写下来。

---

## 总算法：多信号并发→合并取最低

```
连麦人开口（10-60秒语音）
    │
    ▼
提取N个信号（N=2~4）
    │
    ├── 信号1 → 自知X%
    ├── 信号2 → 自知Y%
    ├── 信号3 → 自知Z%
    └── 信号4 → 自知W%
    │
    ▼
合并取最低 = min(X, Y, Z, W)
    │
    ▼
自知等级确定 → 进入锁型匹配
```

**核心原则**：合并取最低。只要有一个信号是0%，整体按0%处理。因为最低自知的那个信号=对方真正的盲区——其他高自知信号可能是"学来的话"而非真正的自省。

## 六层光谱：信号识别表

### L0：0% — 完全不自知（表演型）

| 信号类别 | 具体特征 | 映射词库 |
|---------|---------|---------|
| 绝对词 | 用"肯定""必须""绝对""不可能" | 映射#6：绝对词·自知0% |
| 表演数据 | 抛出大数字但拒绝验证 | 映射#6：表演数据·自知0% |
| 推脱验证 | "不方便""私下给你看""现在不能展示" | 映射#1：被动句·自知0% |
| 复杂度伪装 | "这个事没有那么简单""你不懂这个行业" | 映射#7：复杂度伪装·自知0% |
| 中途改口 | 说了一个数字/方向→被质疑后改口 | 映射#2：流行词·自知0% |

**典型句式**："我们上个月是1.62亿""这个事没有那么简单""我不可能在大庭广众之下展示"

**自知判断逻辑**：对方在表演——他知道自己在表演——但他以为别人看不出来。0%不是"无知"——是"自信地错误"。

### L1：30% — 不自知（概念借用型）

| 信号类别 | 具体特征 | 映射词库 |
|---------|---------|---------|
| 概念借用 | 用流行词但定义不清（"我在做AI"=用ChatGPT写文案） | 映射#2：流行词·自知30% |
| 数据造假 | 数据是真的但夸大了/偷换了分母 | 映射#6：数据造假·自知30% |
| 能力幻觉 | "我觉得我可以""我相信我能行"（但没有行为证据） | 映射#4：能力幻觉·自知30% |

**典型句式**："我在做AI自媒体""我觉得我可以做起来"

**自知判断逻辑**：对方隐约知道自己在夸大——但选择忽略——因为"调整认知"比"面对现实"更痛。

### L2：50% — 萎缩自知（焦虑回避型）

| 信号类别 | 具体特征 | 映射词库 |
|---------|---------|---------|
| 焦虑但回避核心 | 说了很多"困难"但从不提具体数字 | 映射#4：萎缩自知·自知50% |
| 流行词+模糊 | "我想突破""我需要方向"——但没有具体场景 | 映射#2：流行词·自知50% |
| "怎么"前置 | 一直在问"怎么"但没有定义"是什么" | 映射#4："怎么"前置·自知50% |

**典型句式**："我特别迷茫""我需要一个突破方向""行业不行了"

**自知判断逻辑**：对方感觉到了不对劲——但说不清楚——因为没做过具体归因。50%是"我知道有问题"+"但我不知道问题是什么"——这个组合=焦虑但无法行动。

### L3：70% — 隐约自知（框架错误型）

| 信号类别 | 具体特征 | 映射词库 |
|---------|---------|---------|
| 真数据+方向错位 | 给出的数据是真的——但解读方向错了 | 真数据+错方向·自知70% |
| 真诚自省 | 承认自己"没有方法论""可能是坚持错了" | 自省·自知70% |
| 具体困境+框架错 | 困境描述清楚，但归因框架错了（"流量不够"→实际是"产品不行"） | 框架错位·自知70% |

**典型句式**："我从去年10月做到现在没有流量""没有正确的方法论，特别迷茫。合伙人精力不投入"

**自知判断逻辑**：对方知道自己有问题——也知道问题在哪——但"问题在哪"的判断是错的。70%是最值得投入的——因为对方真诚但框架错了——翻锁就能纠正。

### L4：100% — 坦承（开放求助型）

| 信号类别 | 具体特征 | 映射词库 |
|---------|---------|---------|
| 直接承认 | 直接说"我不懂""我需要帮助""我不知道" | 坦承·自知100% |
| 完全开放 | 不给自己的问题设置框架——让别人来定框架 | 开放·自知100% |
| 具体+接受 | 说自己情况很具体→接受任何判断→不辩解 | 接受·自知100% |

**典型句式**："我今年十八岁……你觉得我去上大学还是学焊工证进厂？"

**自知判断逻辑**：对方完全知道自己的处境——没有伪装——没有表演——只是来要更好的框架。100%自知的人不需要破锁——只需要给结构。

## 多信号合并规则

### 规则1：最低原则
取所有信号自知的最低值。理由：最低自知=最大的盲区=必须先解决的那一层。

### 规则2：真>假原则
如果某个信号是"表演型"（假数据/假自省），它的自知权重加倍向下。因为假信号=不自知的最极端表现。

### 规则3：首句优先原则
连麦人第一句话的信号权重最高。因为第一句话=最自然的表达=最接近真实的认知状态。后面的话可能被直播压力/鲁大魔的表情影响。

### 合并示例

| 信号组合 | 合并结果 | 解释 |
|---------|---------|------|
| 0%+0%+0% | **0%** | 全表演→破锁 |
| 0%+50%+70% | **0%** | 有一个0%→整体按0% |
| 30%+50%+70% | **30%** | 最低30%→炸锁 |
| 50%+70%+70% | **50%** | 最低50%→硬锁 |
| 70%+70%+100% | **70%** | 最低70%→翻锁 |
| 100%+100% | **100%** | 全坦承→软锁 |

## 0.5秒执行逻辑

为什么鲁大魔能做到0.5秒判断？因为他不分析——他匹配。

```
听 → 提取关键句 → 匹配映射库 → 自知=映射结果
```

不是"分析这个人"—是"这个句式=这个自知"。他904条对话积累了一个庞大的**句式→自知**映射库——每听到一个新句子——自动匹配最近的模式。

### 训练方法

1. **建库**：从904条LD中提取所有自知0%的句式→分类→形成映射库
2. **速配**：听到一个句子→在0.3秒内匹配最近的句式模式→自知=匹配结果
3. **验证**：看对方的反应——如果对方被破锁后不辩解而沉默=自知判断正确。如果对方急辩=可能高估了自知

## 错判代价

| 错判方向 | 后果 | 修复成本 |
|---------|------|---------|
| 低估自知（0%判成30%） | 给了对方辩解的空间→锁被撬开→局面失控 | 需要补一个更硬的锁→浪费一个回合 |
| 高估自知（70%判成100%） | 给了太软的建议→对方觉得"你没听懂"→信任丢失 | 无法修复——对方不会再连麦 |
| 漏掉假信号 | 被对方的表演骗了→整体判断漂移 | 全链条崩塌——从自知到锁型到武器全错 |

**安全侧**：宁低勿高。判低了可以补硬锁。判高了信任丢失无法修复。
