# 用户问题形成链与知识映射

> 问题是怎样形成的、同类问题怎么演变、问题映射到哪条知识。回答："我遇到了这个问题→它其实是什么问题→去哪找解法？"

## 问题形成链：从认知偏差到假问题

```
真实困境 → 认知偏差 → 错误框架 → 假问题 → 鲁大魔击穿 → 真问题
```

四种困境的完整形成链：

### 链A：资源拼凑型

```
真实困境：我想做事但没有核心资产
    ↓
认知偏差：把"认识的人""谈着的合作""计划中的事"当成"我的资源"
    ↓
错误框架：项目可行性评估——"这个项目有没有戏？"
    ↓
假问题：[[QST-001_资源拼凑型创业者的可行性错觉|QST-001]] — "这个品牌有没有戏？"
    ↓
真问题：你有没有一个自己的东西？
    ↓
映射知识：[[OPI-001_你没有自己的东西之前任何商业计划都是泡沫|OPI-001]] + [[CON-001_老登——行业存量玩家的行为逻辑|CON-001]] + [[SOL-001_从零到一——先有你自己的一个东西|SOL-001]]
```

### 链B：瓶颈误诊型

```
真实困境：已验证的模型增长停滞
    ↓
认知偏差：把后端瓶颈当成前端方向问题
    ↓
错误框架：方向选择——"我该深耕还是换道？"
    ↓
假问题：[[QST-002_增长瓶颈被误诊为方向问题|QST-002]] — "继续带货还是做店铺？要不要做日韩？"
    ↓
真问题：货是不是你的？
    ↓
映射知识：[[OPI-002_电商真正赚钱的都是做供应链的|OPI-002]] + [[SOL-002_测品优先于选区域——电商增长的正确顺序|SOL-002]]
```

### 链C：身份归因型

```
真实困境：成功后失去驱动力和专注力
    ↓
认知偏差：把环境效应当成"我这个人不行了"
    ↓
错误框架：身份审判——"我废了/没有能力了"
    ↓
假问题：[[QST-003_赚钱后失去专注力的身份危机|QST-003]] — "我废了怎么办？"
    ↓
真问题：你待在哪？城市还是旷野？
    ↓
映射知识：[[OPI-003_不是人废了是城市生活方式剥夺了专注力|OPI-003]] + [[CON-002_焦虑覆盖原理——焦虑不可消除但可被专注覆盖|CON-002]] + [[SOL-003_自驾旷野——用被迫专注重置时间感知|SOL-003]]
```

### 链D：捷径幻想型

```
真实困境：需要搭建团队但没有管理方法
    ↓
认知偏差：把"找到对的人"当成"搭好团队"
    ↓
错误框架：渠道问题——"从哪招人更快？"
    ↓
假问题：[[QST-004_想快速搭团队但不理解人力漏斗|QST-004]] — "从哪些公司/渠道招人？"
    ↓
真问题：你有没有筛选系统？
    ↓
映射知识：[[OPI-004_团队是漏斗筛选出来的不是一次招到的|OPI-004]] + [[CON-003_人力漏斗——团队搭建的系统流程|CON-003]] + [[SOL-004_招聘漏斗四步法——从大量招聘到持续循环|SOL-004]]
```

## 问题演变规律

同类问题的提问方式会随行业/阶段变化，但底层结构不变：

```
资源拼凑型的不同嘴型：
  "这个品牌有没有戏？"（羽毛球）
  → "这个跨境项目能不能做？"（跨境电商）
  → "这个AI产品有没有市场？"（科技创业）
  → "我能不能开这个店？"（实体）
  └── 底层同一问题：我有没有自己的东西？

瓶颈误诊型的不同嘴型：
  "要不要做日韩市场？"（TK带货）
  → "要不要换平台？"（电商）
  → "要不要换品类？"（实体店）
  → "要不要换打法？"（服务）
  └── 底层同一问题：后端是不是我的？

身份归因型的不同嘴型：
  "我废了/没能力了"（赚到钱的）
  → "我不适合做这个"（没赚到钱的）
  → "我可能不是这块料"（刚起步的）
  └── 底层同一问题：我待在哪？

捷径幻想型的不同嘴型：
  "从哪招人快？"（团队）
  → "怎么快速起号？"（流量）
  → "怎么快速变现？"（变现）
  └── 底层同一问题：我想跳过系统性的长周期动作
```
