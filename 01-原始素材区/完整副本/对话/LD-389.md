# LD-389 · 创业失败多次——骗不了人？那就好好送外卖，创业讲本分不讲情分

## 表演 · 教学

**L1** *"那就好好送外卖吧宝贝儿，也是一个好的人生。创业得讲本分，不能讲情分。讲情分别去创业。实在不行找个心理咨询。"*

**框架植入**：[定义源→下游展开] "骗不了人"=你把"收钱"说成了"骗"——你以为让一个人掏钱买你的东西=你在骗他——但这不是骗——是交换——你给他东西——他给你钱——这是本分——你完成你的承诺=不是骗——不完成=才是骗——你说"有些话说不出"=你把销售说成骗——把营销说成违心——但你每天给客户送外卖——外卖小哥=递上餐——"用餐愉快"=说一句——你跟他说=这句也是说——你说了——你不是在骗——是在服务——服务=本分——收钱=也是本分——你受不住——因为你"赚得多了都受不了"——你怕多赚别人钱=你在占他便宜——但占便宜的前提=你的产品不值它的价格——你的东西值=你没在占——你在提供价值——价值=大小=客户自己判断——他要继续买=是你的价值够了——但要觉得不值=他下次不买了——你控制不了——这不是你的问题——是他的感受——你把他的感受=变成你的道德负担——你扛了不该你扛的东西——你替你的客户=心疼他的钱——但谁请你替了——他赚了钱=他有他的判断——他掏钱的时候=他算过了——算得比你清——你以为他傻=他不是——是你把这个交换——写成了"欺负"——你的词汇=变形了。最核心的在最后一句——"创业得讲本分，不能讲情分"——本分=你给了产品——他花了钱——公平=不需要额外关心"他花这钱值不值"——因为你已经给了——情分=你在替他想——你在把交换当成了"我得对得起你的钱包"——但你在创业——不是在做慈善——你卖东西=你收钱=你付房租=你请员工=你给国家交税=你雇外卖小哥=你也给外卖小哥结账——你对得起所有人——本分=做到——做到了=够了——多余=你的情分——你的情分=在把你拖下马——你每次交易完=你觉得心里不舒服=因为你在情分上——你觉得是在骗——因为你已经给了自己一个前置假设——"销售=骗"——但销售不是——销售=把东西给要的人——他把钱给你——他拿东西——双方都满意=交换=双方都赚——你不是在骗——你是在恐惧——怕哪天你的客户突然说"你骗了我"——但那个恐惧=不是从他那里来的——是你自己带来的——你不适合创业——不是因为你能力不行——是你要通过这个心理坎——不通过=你就留在送外卖——送外卖=也是本分——你送一单拿一单钱——你不觉得骗他——你心里平衡——为什么外卖平衡？因为你把食物递到他手里=实物——创业不是实物——是信任——你不敢要信任=因为你觉得自己不值——但值=不是你说了算——是客户说了算——客户给你钱=他判断你值——你只需要做一件事=交付——不是判断。

**演示手段**：[展开·手段层] **手段#3·起点终点反转+手段#8·叙事翻转**。起点终点反转：起点="我创业失败=我太善良"→终点=你的善良被翻译为"骗不了人"="我不敢收钱"——这不是善良——是自我价值感低——你收回自己对自己的价值=你就能创业了。叙事翻转："骗不了人=我的缺陷"→"骗不了人=你不用骗——但你不信'不用骗也能赚钱'——不是你骗子——是你被了一种叙事='所有商人都骗子'——你打破这个叙事=你就能卖——不用骗——凭本事卖"。

**句式提取**："那就好好送外卖吧宝贝儿" / "创业得讲本分不能讲情分" / "讲情分别去创业" / "也是一个好的人生"

**L3.5b 表演产出**：你"骗不了人"=不是缺点——是优点——骗人=短期赚——长期死——骗不了人=你只能卖真实的东西——真实=竞争力——但你不敢卖——因为你觉得"卖"就是"骗"——把这两个词拆开——一个是你脑子里的害怕——另一个是客户手里的选择——客户=你不需要替他心疼他——他心疼了自己——你就做你该做的——给东西——收钱——说"谢谢"——下一单。
**物锚点**：用户叙事="—"——行为事实=———语法事实={—}——偏离度={叙事回避事实}。

**L5** —（表演·翻转——"骗不了人"不是创业的阻碍——是你把商业叙事套上"骗"的枷锁——如果放不下=送外卖也是正当人生——不是失败——是自知——自知你现在的心理状态不适合创业=等准备好再来——或者永远不来=也可以=是完整的）

### 鲁大魔人格
- 话语不信任：激活——不信任"所有商人都很骗"的叙事——本分=比情分更高级的责任——把产品做好=尊重——不是把利润退回去
- 误判容忍：未激活——这是温柔的——"宝贝儿"=不是冒犯——是归位——他把对方当成值得同情的人——但也知道不能姑息他把"不敢卖"包装成"善良"
- 拆解快感：未激活——这不是拆解的兴奋——是伦理定义——需要沉着——不是战斗状态

鲁大魔："我之前创业失败很多次，开过装修公司五金店。现在做外卖。心理问题——搞不了成人用品，话说不出口。我这人骗不了人，赚多了都受不了。想拍短视频但又打不开心关。那就好好送外卖吧宝贝儿，也是一个好的人生。创业得讲本分不能讲情分。讲情分别去创业。实在不行找心理咨询。"
