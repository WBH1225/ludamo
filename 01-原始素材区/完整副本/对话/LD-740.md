# LD-740 · 插话的人活该招不到人

## 拆解
### 连麦人
**原话**："我是TikTok品牌负责人，安防类产品，在某国做到单日销量第一。现在想拓展亚马逊，把TK流量引流过去。想搭亚马逊团队，问从哪些公司/渠道招人好？之前招了个亚马逊运营，投关键词ROI到10，出了二三十单，但一个运营已经走了自己出去干，现在两个运营状态摸鱼推进慢。" 鲁大魔回答时连麦人频繁插话"对对对""我们确实是这样"——被鲁大魔打断训斥。

[多信号并发] 5信号
信号A："TK做到品类第一"+"安防产品"→产品力和TK运营能力强——有成功经验做背书
信号B："想一两个月搭建团队"+"没有投资需求"→对"团队搭建"的认知严重不足——以为招人=搭团队
信号C："一个走了一个摸鱼"→两个样本就下结论"招人难"——样本太小，没有系统招聘流程
信号D：频繁插话"对对对"——在别人说话时找共鸣而非听答案——沟通习惯=管理瓶颈
信号E：鲁大魔说"招人需要人力漏斗"→马上接"对对对，我体会特别深"——没等别人说完就跳跃到分享自己的感受

**瞬间融合** → 四面：
身份面：成功的TK运营者，试图跨平台扩张——有单点能力但缺乏系统管理能力
能力面：TK运营强，亚马逊刚开始试水——跨平台能力待验证
情绪面：成就感（品类第一）+焦虑（招不到人）——双重心境让他急于获取"快速方法"
语境面：跨境电商人才竞争激烈——好运营本来就难招，加上TK→亚马逊的跨平台要求更难

**被动**："我想快速搭团队"→"我不理解团队是漏斗筛选出来的，不是一次招到的"。**缺的不是/缺的是**：招聘渠道/对"团队搭建=长期漏斗筛选"的认知
**物锚点**：用户叙事="我是TikTok品牌负责人，安防类产品，在某国做到单日销量第一。现在想拓展亚马逊，把TK流量引流过去。想搭亚马逊团队，问从哪些公司/渠道招人好？之前招了个亚马逊运营，投关键词ROI到10，出了二三十单..."——行为事实=———语法事实={"我想快速搭团队"→"我不理解团队是漏斗筛选出来的，不是一次招到的"}——偏离度={概念藏事实}。

### 鲁大魔 · 解决思维
**思维类型：变量压缩（主） + 阶段归位 + 行为证据思维**

[切] —

**L1** *"人力这个东西，有工作效率能够有工作结果的才叫团队。搭建一个能够产出正常结果的团队，需要把一个人力漏斗——通过大量市场招聘→工作结果筛选→长周期的事情。"*

**L2** **问题定位：你要一两个月搭团队——团队是漏斗筛选出来的，不是一次招聘凑出来的。**

**L3** **核心矛盾：你以为缺的是"更好的招聘渠道"——其实缺的是"人力漏斗"的管理认知+耐心。没有快速方法。**

**L4** **变量压缩·人力漏斗：团队搭建=大量招聘→工作试用→结果筛选→淘汰不适合→留下能打的。这不是一两个月的事——是全时段的事。** 把"搭团队"这个模糊目标压缩成人力漏斗的四个步骤。没有魔法渠道——安克/赛维/绿联的初级运营也不会来了就立刻匹配你的业务。漏斗的核心逻辑：招10个→试3个月→留2个→这才是正常比例。你想要"精准命中"=你不尊重概率。

**L5** **解决路径：公开市场招聘→大量招→用工作结果筛选→漏斗自然产出能打的。没有捷径。**

🔑 **原句：**
> "有工作效率能够有工作结果的才叫团队。"
> —— 变量压缩。团队≠人数。团队=产出结果的一群人。光招人不算搭团队。
> "你们活该做不好事情。人家没说完，你就'对对对'——你要的是解决办法还是让我跟你产生共鸣？"
> —— 行为证据思维。从连麦人的插话行为推断出他的管理问题——不愿意听完整信息就跳跃到共鸣=管理中也一定有"没听完就做决策"的问题。这是导致招人留不住人的深层原因之一。

**L4信念** **信念#5变量≤3论**。团队搭建的变量压缩：招聘量→筛选期→留存率。不要想"哪个渠道好"这个无限变量。✅

### 五闻四锁
闻0自知嗅觉 → 自知30%——知道自己招人遇到困难，但不承认"想一两个月搞定"本身就是问题——躁进
闻1框架嗅觉 → 连麦人框架：渠道选择问题。鲁大魔翻框架：流程管理问题——不是"在哪招"，是"怎么筛"
闻2功能嗅觉 → 连麦人需要"快速方案"——鲁大魔给的是"长期系统"——功能降级：去躁气
闻3身份嗅觉 → 连麦人是"成功但着急的创业者"——鲁大魔把他打回"不够耐心的管理者"
闻4语法嗅觉 → "渠道/公司/挖人"→捷径词汇。"漏斗/筛选/周期"→系统词汇——鲁大魔用系统语法替代捷径语法

**物锚点映射** → 行为事实≈闻2验证。语法事实≈闻4还原。偏离度≈闻0自知%。三角闭合：人(30%)↔事(问题类型)↔物(行为+语法)。



锁1力度定标 → 强（硬锁）。"活该你做不到"+"你天天插话"——不只在说团队，还在说沟通习惯——双重硬锁
锁2锁扣锻造 → "人力漏斗"——锁扣从"哪里招人"转成"怎么筛选人"
锁3执行选式 → 招聘漏斗公式：大量招聘→工作试用→基于结果筛选→留下能打的→持续循环
锁4闭环嗅探 → 如果连麦人说"但我需要快速"→锁死：没有快速——你TK品类第一也不是一两个月做出来的
