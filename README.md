## 这不是什么

- ❌ 不是鲁大魔课程的笔记整理
- ❌ 不是"AI套壳"——框架来自鲁大魔，诊断引擎从 904 条对话中蒸馏
- ❌ 不是通用聊天机器人——只做诊断和学习两件事，边界清晰

## 这是什么

- ✅ 一个能**判你思维对不对**的诊断管道
- ✅ 从 904 条对话中统计出的**13种问题类型 × 5种锁型 × 17种武器**的完整框架
- ✅ 每个诊断结果都附带**真实案例对照**（不是编的，每个案例可追溯到原始对话编号）
- ✅ 可部署在 Claude Code 中的独立 Skill 文件

## 生态圈原则

**架构有的 → 拿来用。GitHub 上的 → 当自己的。外部可利用的 → 当自己的。缺少的 → 自己建。**

- 鲁大魔框架提供底层商业思维，我建 Skill 把它变成可操作的诊断工具
- 每个 Skill 跨域交叉：商业诊断 × AI 判断 × 教育体感 × 内容制作
- 免费 Skill 帮你自助诊断，深度问题我亲自下场帮你捋

除了这 4 个 Skill，后续会持续建：
- 认知视频脚本生成器（商业概念→可视化视频）
- 状态扫描器（15-20个问题自检当前阶段）
- 路径匹配器（基于扫描结果推荐适配的 Skill 组合）
- 多框架交叉诊断（鲁大魔 × dbs × 薛辉 × 行业分析）

1. 下载本仓库

3. 在 Claude Code 中输入 `/鲁大魔` 启动总入口
4. 或者直接在 Claude Code 对话中说你的问题——Skill 会自动触发
